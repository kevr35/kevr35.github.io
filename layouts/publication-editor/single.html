Next steps

  1. Review the fields above, choose the image option, and set Keep as draft if you are not ready to publish.
  2. If running python tools/site_editor.py locally, click Save to content/publications/ to write and rebuild directly. Otherwise, click Download Hugo Markdown and put the file in content/publications/ yourself.
  3. If you chose a local image, put that image in static/previews/ using the path in the image field. Favicon mode does not require an image file.
  4. Run hugo --minify (done automatically by the local save), review the result, then commit and push the Markdown file and any local image.
