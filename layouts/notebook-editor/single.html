Paste a Wolfram Cloud "Embed Code" link for a published notebook, review the fields below, then download a Hugo notebook file. Nothing is uploaded or published by this page — the notebook itself must already be published to the Wolfram Cloud.

Next steps

  1. Confirm the notebook is published to the Wolfram Cloud with public sharing enabled, so the embed URL loads for visitors.
  2. Review the fields above and set Keep as draft if you are not ready to publish.
  3. If running python tools/site_editor.py locally, click Save to content/notebooks/ to write and rebuild directly. Otherwise, click Download Hugo Markdown and put the file in content/notebooks/ yourself.
  4. Run hugo --minify (done automatically by the local save), review the result, then commit and push the Markdown file.
