Bulk import a tick list

On Mountain Project, open your profile, choose Ticks, then Export to download a CSV of every logged ascent. The importer matches each source location and crag to the existing registry. For an unfamiliar pair, choose its standard destination before any files are written. Existing routes (matched by filename or Mountain Project URL) are skipped unless you allow overwriting.

Available only in the local editor. Run python tools/site_editor.py and open this page at http://127.0.0.1:8000/admin/climbing/.

Rebuild the location registry

Scans every saved route in content/climbing/, cleans up naming issues (like Mountain Project's * starred-crag marker), and adds any crag or location missing from data/climbing/locations.yaml. Safe to run any time the map is missing a location, including after manual edits.

Manage a crag

Rename a mislabeled crag, or split a lumped-together one (like "CT Bouldering") into its real sub-crags. Every route that matches gets its crag (and location) updated together, and data/climbing/locations.yaml stays in sync so future imports from the same crag inherit the fix.

Available only in the local editor. Run python tools/site_editor.py and open this page at http://127.0.0.1:8000/admin/climbing/.

Location hierarchy

Select a node in the graph to rename it or choose its parent. Crags must belong to a location; locations must belong to a state. Saving updates every affected route and rebuilds the site.

Available only in the local editor.
